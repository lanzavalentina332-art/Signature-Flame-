# Signature Flame

A responsive, English-language website for Signature Flame, inspired by Colombian Día de las Velitas traditions.

## Files
- `index.html` — page content and structure
- `style.css` — responsive design and light/dark themes
- `script.js` — theme toggle and mobile navigation
- `images/` — product photos used in the hero and product gallery

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `signature-flame`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.

No build tools are required. The candle artwork is made with CSS, so the page works without local image assets.
